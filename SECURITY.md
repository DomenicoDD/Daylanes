# Security

Daylanes keeps its ledger on your Mac and stores integration credentials in the macOS Keychain. Please report anything that could expose that data, run code, or bypass the official build's licensing.

## Reporting a vulnerability

Email **support@daylanes.app** with "Security" in the subject. Include the version, steps to reproduce and the impact you expect. Please do not open a public issue for a vulnerability.

You will get a reply within a few working days. Once a fix ships, you are welcome to be credited in the release notes.

## Supported versions

Security fixes go into the latest release. Builds from source should track `main`.
